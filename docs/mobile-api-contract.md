# Mobile Go API contract

The Go package import is `github.com/gamelink-project/gamelink/mobile`. All exported API uses gomobile-compatible types. Go owns invitation validation, Tailcat connections, LAN discovery, signaling, and media. Native integration tests exercise synthetic discovery, signaling, and bidirectional media through Tailcat. Console interoperability and physical Android validation are still pending.

- `GenerateIdentity() ([]byte, error)` generates opaque UTF-8 private key bytes. Store them in Android Keystore-protected storage and never log them.
- `PublicKey(privateKey []byte) (string, error)` returns the shareable `nodekey:` public key.
- `PreviewInvitation(text string) (string, error)` validates the invitation using canonical production validation and returns JSON with `name`, `game`, `protocol`, `port`, optional `note`, integer `consoleBridge` (zero means unsupported), and `details` (safe relay and server fingerprint details). It never returns the invitation or secret address.
- `Start(configJSON string, privateKey []byte) (*Runtime, error)` validates the config, key and invitation, then returns promptly before dialing. The runtime copies key material and starts its network work asynchronously. `configJSON` has `invitation` (the full secret invitation), `lanIPv4` (a selected private LAN IPv4 address), optional `lanPrefix` and `interfaceIndex` (Android-provided selected Wi-Fi details; both may be omitted on native systems), and optional `allowLocalRelay` (boolean, default false; explicit local testing opt-in). Loopback LAN addresses are accepted only with that opt-in. The invitation must carry `consoleBridge: 1`; older or unsupported invitations return `unsupported_bridge`. `Start` never persists secrets.
- `Runtime.Stop()` is idempotent and cancels startup, active sessions and network resources. It works while connecting and waits at most five seconds for cleanup.
- `Runtime.Status() string` is safe to poll and returns JSON containing `state` (`connecting`, `connected`, `reconnecting`, `unreachable`, `error`, or `stopped`), a sanitized `message`, optional stable `code` (currently `unsupported_bridge`), a non-sensitive `stage` (`relay_resolution`, `tailcat_tcp`, `tailcat_udp`, `lan_discovery`, `bridge_advertisement`, `ready`, or `stopped`), `path` (`direct`, `relay`, or `unknown`), and `sessions` (integer). Offline and unapproved are intentionally reported with the same `unreachable` state. Status never contains private keys, invitation text, Tailcat addresses, SDP, ICE credentials, or console/server endpoints. Once stopped it remains stopped.

Android should keep the returned runtime immediately, including while `state` is `connecting`, so the service can stop it during connection. No callback is required; poll status off the UI thread. Go owns LAN discovery, authenticated signaling, and the fragmented media relay; Android supplies only the selected Wi-Fi address, prefix, and interface index.
